# Fee Receipt Generator using Java and XML

## 📌 Overview
The Fee Receipt Generator is a Java-based desktop application that generates student fee receipts and stores them in XML format. It automates fee calculation and maintains structured records for easy retrieval.

---

## 🚀 Features
- Add student details (Name, Roll No, Course, etc.)
- Enter multiple fee components
- Automatic total fee calculation
- Generate formatted receipt
- Store receipt data in XML file
- Retrieve and view stored receipts
- Simple and user-friendly interface

---

## 🛠️ Technologies Used
- Java (Core Java / Swing / AWT)
- XML
- DOM / SAX Parser
- File Handling
